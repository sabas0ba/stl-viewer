# STL Viewer (単一 HTML / 3D プリント前チェック)

外部依存を持たない単一 HTML の STL ビューア。ファイルはブラウザ内でのみ処理し、
ネットワーク送信は一切行わない。オフライン環境およびファイル URL (`file://`) で動作する。

- 公開ページ: `https://<ユーザ名>.github.io/stl-viewer/`
- 単体ファイル: `dist/stl-viewer.html` (ダウンロードしてローカルで開けばオフラインで動作する)

## 機能

| 区分 | 内容 |
| --- | --- |
| 読み込み | binary / ASCII STL、複数ファイル、ドラッグ & ドロップ |
| 寸法 | 外形 X/Y/Z、対角、配置範囲、体積、表面積、重心、2 点間計測 (頂点スナップ付き) |
| 3 面図 | JIS 第三角法配置 (平面図 / 正面図 / 右側面図 + 等角図)、正投影ビューは中心と縮尺を共有 |
| 品質 | 水密性、境界エッジ、非多様体エッジ、向き不整合、縮退三角形、シェル数、法線反転の自動是正 |
| 向き | 軸ごとの 90 度回転、任意角回転、オイラー角指定、面クリックによるベッド接地、自動姿勢探索 |
| 断面 | X/Y/Z クリップ平面 (反転可)、ステンシルによる切断面の充填、輪郭抽出と断面積・輪郭長・ループ数。3D の切断位置・2D 輪郭・図面の断面はすべて同じ平面を参照する |
| 複数パーツ | パーツ一覧、個別の表示・色・変換、複製、自動整列、三角形レベルの干渉判定 |
| 中抜き | 造形方向を基準に内部を空洞化。壁厚 / 天面厚 / 底面厚の個別指定、内部構造 (格子・ジャイロイド)、抜き穴、材料削減量と断面性能の比較 |
| 実寸出力 | 正投影の輪郭線を 1:1 の PDF / SVG で出力。用紙分割 (重ね代・位置合わせ十字)、寸法線、100 mm 校正スケール |
| ステージ | 矩形 / 円形 (デルタ機) の切替、任意サイズ、グリッド間隔、モデルに合わせる、URL への設定保存 |
| 造形前確認 | ビルドプレート枠と範囲外警告、オーバーハング着色と要サポート面積、接地面積、材料質量 |
| 書き出し | 変換適用済み binary STL、PNG、計測レポート (テキスト) |

座標系は X 右 / Y 奥 / Z 上、単位は mm、Z=0 がビルドプレート面。

### 実寸 PDF について

紙に印刷して現物と突き合わせる用途を想定している。

- 出力は輪郭線のベクタ図形で、ラスタ化を経ないため寸法誤差は生じない。
- 印刷時は「実際のサイズ / 100%」を指定し、用紙に合わせる設定を切ること。
  各ページ下部の 100 mm 基準線を定規で測れば、プリンタ側の倍率ずれを検出できる。
- 用紙より大きい図は自動で分割される。ページ間には重ね代 (既定 10 mm) と位置合わせ十字が入る。
- フォントを埋め込まないため、PDF 内の文字は ASCII のみ (非 ASCII は `?` に置換)。
  日本語表記が必要な場合は SVG 出力を利用する。
- 検証: 生成した PDF を 300 dpi でラスタ化し、100 x 60 mm の板の輪郭と 100 mm 基準線を
  画素単位で計測する自動テスト (`test/pdf-scale.test.mjs`) を用意している。

### 中抜き (フィラメント削減)

中抜きタブで、選択したパーツの内部を空洞にした新しいパーツを作る。計算は**現在の向き**で
行うため、先に向きを決めてから実行すること (Z が造形方向)。

| 項目 | 内容 |
| --- | --- |
| 壁厚 | 表面の法線方向に確保する厚み |
| 天面厚 / 底面厚 | 造形方向 (±Z) に沿って確保する厚み。天面は空洞の上を渡るブリッジになるため厚めにする |
| 内部構造 | なし (完全な中空) / 格子 (直交する縦リブ) / ジャイロイド (等方・自己支持)。充填率とリブ厚で密度を決める |
| 抜き穴 | 底面または上面に貫通穴を開ける。光造形の未硬化樹脂や FDM の内圧を逃がす |
| 出力 | 「外殻を保持」は元の面をそのまま使い内側に空洞を足す。「全体を再構築」は等値面から作り直す (抜き穴とメッシュ修復が可能、外形はボクセル解像度の近似になる) |
| 格子間隔 | ボクセルの一辺。0 で自動 (最小形状の 1/3、格子点数の上限で丸める) |

結果には削減した体積・質量・フィラメント長に加えて、層ごとの**断面二次モーメント比**
(弱軸、中実との比の最小値) と断面積比を表示する。曲げ剛性は断面二次モーメントに比例するため、
「どれだけ材料を減らしても剛性が残るか」の目安になる。壁を外周に残す中抜きでは、
体積を半分にしても断面二次モーメントは 6 割程度残る。

実装は次の 3 段階で、外部ライブラリを使わない。

1. 等方格子で符号付き距離場を作る。表面近傍だけ三角形までの厳密距離を求め、そこから
   チャンファ変換で伝播させる。内外判定は +X 方向の巻き数で行うため、多少壊れた
   メッシュでも破綻しにくい。
2. 距離場から壁厚を引き、造形方向の厚み・内部構造・抜き穴で削って空洞の場を作る。
3. surface nets で等値面を三角形化する (表引き不要で、出力は多様体かつ閉じている)。

### ステージ (造形エリア)

配置タブで形状 (矩形 / 円形)、サイズ、グリッド間隔を変更できる。設定は URL に反映されるため、
`?bed=250x210x210` や `?bed=circle:180x300&grid=25` の形でブックマークできる。

## 操作

- ドラッグ: 等角図は回転、正投影図は平行移動 (Shift または中ボタンで常に平行移動)
- ホイール / ピンチ: 拡大縮小 (カーソル位置基準)
- クリック: パーツ選択 / ダブルクリック: 注視点移動
- `F` 全体表示、`Q` 3 面図切替、`1`-`6` 視点、`Del` 削除、`Esc` モード中止 / 断面解除

断面を表示している間は画面下のステータスバーに「断面表示中」が出る。これはタブに関係なく
表示され、クリックすると解除できる。断面タブの「すべて解除」と `Esc` でも解除できる。

## 実装メモ

- レンダラは WebGL2 を直接使用する。ライブラリ依存なし。
- クリップ平面はフラグメントシェーダの `discard`、切断面の充填はステンシル
  (裏面 INCR / 表面 DECR → 非ゼロ領域に平面を描画) で行う。
- ピッキングと干渉判定は中央値分割 BVH。干渉は AABB で粗く絞ってから三角形交差
  (分離軸判定) で確定する。三角形数が多い場合は間引き、判定を打ち切った旨を表示する。
- 断面抽出は平面上の頂点を上側として分類し、長さ 0 の線分を除去する。これにより
  切断面がメッシュの頂点列と一致しても輪郭が二重化しない。
- オーバーハングは下向き面の法線 n について beta = asin(-n.z) を用いる
  (垂直壁 0 度、水平下面 90 度)。beta > しきい値で要サポートと判定し、
  ベッド接地面は除外する。
- 法線はファイル記載値を使わず頂点順序から再計算する。符号付き体積が負の場合は
  面の向きを一括反転して是正する。

## 公開 (GitHub Pages)

`main` へ push すると `.github/workflows/pages.yml` が `dist/` を GitHub Pages へ配置する。
リポジトリ側で以下を一度だけ設定する。

1. GitHub にリポジトリを作成し push する。
2. Settings → Pages → Build and deployment → Source を **GitHub Actions** にする。
3. Actions タブでワークフローが完了すると `https://<ユーザ名>.github.io/<リポジトリ名>/`
   で公開される。

`dist/` はリポジトリにコミットしている。ソースを変更したら `node build.mjs` を実行して
生成物も一緒にコミットすること (CI の `node build.mjs --check` で同期を検査する)。

## 開発

```sh
node build.mjs                 # src/ -> dist/index.html, dist/stl-viewer.html
node build.mjs --check         # コミット済み dist がソースと一致するか検査
node test/make-fixtures.mjs    # 検証用 STL を生成
node test/core.test.mjs        # コア処理の単体テスト (50 件)
node test/pdf-scale.test.mjs   # PDF を 300dpi でラスタ化して実寸を計測 (poppler が必要)
NODE_PATH="$(npm root)" node test/browser.test.mjs   # headless Chromium での結合テスト (51 件)
```

nix を使う場合は `nix develop` で node 22 と結合テスト用 Chromium が入る。
`nix build` は単一 HTML を `result/share/stl-viewer/index.html` に生成する。

`src/js/*.js` はファイル名順に連結して 1 つの即時実行関数に格納される。DOM や WebGL に
依存しないモジュール (`00`-`42`, `70`, `85`) は Node の `vm` 上で単体テストできる。
実装方針とディレクトリ構成は `CLAUDE.md` にまとめている。

### 初回に必要な作業

`package-lock.json` は生成済みである。nix を使う場合のみ、`flake.lock` が未生成のため
一度だけ以下を実行してコミットすること (生成環境に nix がなかった)。

```sh
nix flake update   # flake.lock を生成 (nix を使う場合のみ)
```

## 制限

- 対応形式は STL のみ (3MF / OBJ / STEP は非対応)。
- PDF の図面は隠線処理を行わない。輪郭線は厳密だが、稜線表示を有効にすると
  裏側の稜線が一部含まれることがある。
- 表面積の値は非一様スケール時のみ近似値になる。
- 中抜きはボクセル法のため、壁厚には格子間隔と同程度 (既定で壁厚の 1/3 以下) の誤差が出る。
  格子間隔に対して細い内部構造を指定すると、リブの交差部に非多様体エッジが数本残ることがある
  (体積は閉じているためスライサでは扱えるが、気になる場合は格子間隔を細かくするかリブを太くする)。
- 断面積は閉ループの入れ子関係から算出するため、自己交差のあるメッシュでは誤差が出る。
- 読み込みはメインスレッドで行う。数百万三角形のファイルでは一時的に UI が停止する。
